A workspace file can list views of its graphs, each with its own profile, parents rule, layout and filters, and the profile key layout.groupBy: parents nests the grouped layout by the parents rule of each kind. The serve command reloads the open page when a file changes and keeps the view, scope, selection, layout and filters. The details panel has a Source section with the path and the text of the file of a node. The profile key source.origin and the workspace key sourceRoot set the file and the source root, and build --sources puts the texts into the page.
